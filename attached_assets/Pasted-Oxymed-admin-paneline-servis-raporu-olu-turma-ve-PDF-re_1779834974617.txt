Oxymed admin paneline servis raporu oluşturma ve PDF üretme sistemi ekle.

Elimde mevcut servis raporu tasarımı var:
- ServicePageTaslak.tsx
- ServicePageTaslak.css

Bu dosyaları PDF template olarak kullan. Admin panelde girilen tüm servis verileri bu tasarıma yerleşsin ve A4 landscape PDF olarak oluşturulsun.

Amaç:
Admin panelden bir cihaz seçilecek, servis raporu bilgileri girilecek, fotoğraflar ve imzalar eklenecek, sistem ServicePageTaslak tasarımını bu bilgilerle dolduracak ve PDF çıktısı oluşturacak. Oluşturulan PDF cihazın servis geçmişine kaydedilecek. Ürün üzerindeki QR kod okutulduğunda açılan /servis/cihaz/:publicToken sayfasında servis geçmişi görünecek ve PDF raporlar görüntülenip indirilebilecek.

Teknoloji:
- React + TypeScript
- Tailwind veya mevcut CSS
- Node.js / Express veya Next.js API
- PostgreSQL
- PDF oluşturma için Puppeteer veya Playwright
- Dosya yükleme için local storage veya S3/R2 uyumlu object storage
- QR kod sistemi mevcut cihaz public_token yapısıyla çalışsın

PDF Oluşturma:
ServicePageTaslak.tsx componentini data-driven hale getir.
Hardcoded metinleri props/data üzerinden doldur.
ServicePageTaslak.css dosyasını print uyumlu hale getir.
PDF A4 landscape olacak.
CSS:
@page { size: A4 landscape; margin: 0; }
print-color-adjust: exact kullanılacak.

PDF üretim akışı:
- Admin formu doldurur
- Önizle butonuna basar
- ServicePageTaslak datayla render edilir
- PDF Oluştur butonuna basınca Puppeteer/Playwright ile PDF oluşturulur
- PDF dosyası storage’a kaydedilir
- pdf_url service_reports tablosuna yazılır
- cihazın servis geçmişine bağlanır

Servis geçmişi:
Cihaz public servis sayfası oluştur:
Route:
/servis/cihaz/:publicToken

Bu sayfada:
- ürün adı
- model
- seri no
- garanti durumu
- son bakım tarihi
- sonraki bakım tarihi
- servis geçmişi listesi
görünsün.

Servis geçmişinde her rapor için:
- rapor no
- tarih
- servis türü
- işlem durumu
- PDF görüntüle
- PDF indir
butonları olsun.

Rapor doğrulama sayfası:
Route:
/servis/rapor/:verificationToken

Bu sayfada raporun doğrulanmış olduğu, rapor no, cihaz seri no, tarih ve PDF görüntüleme linki yer alsın.

Güvenlik:
- Public servis sayfasında gizli admin notları görünmesin.
- Detaylı teknik notlar sadece admin/servis kullanıcısına açık olsun.
- PDF raporlar public görüntülenebilecekse sadece verification token ile erişilsin.
- Her işlem activity_logs tablosuna kaydedilsin.
- Rapor kesinleştikten sonra silinmesin; revizyon mantığı olsun.
